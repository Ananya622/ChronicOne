# ChronicOne 🩺

### A simple and personalized way to stay consistent with chronic condition care.

ChronicOne is a web application designed to help people manage their daily health routines and stay consistent with the habits that matter to them.

Instead of keeping health-related information scattered across notes or different applications, ChronicOne brings **daily check-ins, habit adherence, health measurements, mood, progress, and recovery** into one place.

The application adapts the tracking experience according to the user's selected health conditions.

---

## 🌱 Why ChronicOne?

Managing a chronic condition is not only about recording health measurements. **Long-term consistency matters too.**

ChronicOne focuses on questions such as:

- How consistent have I been recently?
- Did I complete today's important habits?
- How is my adherence changing over time?
- What happened on a particular day?
- How are my health measurements changing?
- What happens if I miss a few days?
- Can I get back on track after a setback?

The goal is to make health tracking feel **simple, visual, and encouraging** rather than like a medical form.

---

## ✨ Key Features

### 📋 Daily Check-in

Users can complete their daily health-related habits and receive an automatic adherence score.

Each day is classified as:

- 🟢 **Full**
- 🔵 **Partial**
- 🟠 **Low**
- 🔴 **Missed**

The dashboard provides a quick overview of the user's daily progress.

---

### 🔥 Streak & Consistency Tracking

ChronicOne keeps track of:

- Current streak
- Best streak
- Grace days
- Relapse detection
- Recovery progress
- Recovery bonus

The streak system is designed to encourage consistency while allowing users to recover after setbacks.

---

### 🛡️ Grace Days & Recovery

Users have a limited number of grace days that can protect their consistency during occasional missed days.

If a relapse occurs, ChronicOne can track a recovery period.

Completing the recovery period can provide an additional recovery bonus.

This creates a more realistic consistency system instead of simply resetting everything after one bad day.

---

### ❤️ Health & Biomarkers

The Health section allows users to record condition-related measurements such as:

- Blood Pressure
- Body Weight
- Heart Rate
- Blood Glucose
- Peak Flow
- Joint Pain
- Sleep Duration

Health records are stored with their dates so historical readings can be reviewed separately.

The biomarkers shown can also change according to the user's selected health conditions.

---

### 😊 Wellness & Mood

Users can record how they are feeling physically and mentally.

This allows wellness and mood information to be viewed alongside daily adherence and health progress.

---

### 📅 Calendar & Adherence Heatmap

The Calendar provides a visual overview of consistency over time.

Each day is represented using a color based on its adherence level.

Users can:

- View a complete month
- Navigate between months
- See the last 7 days of consistency
- Hover over a day for a quick summary
- Click a day to see detailed information

The Day Details view can show:

- Overall adherence
- Habit-by-habit percentages
- Daily notes
- Mood
- Health measurements recorded on that date

---

### 📊 Personalized Dashboard

The dashboard brings the most important information together in one place.

It includes:

- Current streak
- Best streak
- Grace days
- Today's adherence
- Today's habit progress
- Wellness & mood
- Recent consistency
- Health biomarkers
- Achievement progress

The dashboard is personalized according to the user's selected health conditions.

---

### 🎯 Condition-Based Tracking

ChronicOne adapts the tracking experience based on the conditions selected during onboarding.

For example, if a user's selected condition requires blood pressure monitoring, the relevant blood-pressure tracking option is included in their dashboard.

This helps users focus on measurements and habits that are relevant to their individual tracking needs.

---

### 🏆 Achievements

ChronicOne includes an Achievements section to make the experience more engaging.

Users can unlock achievements based on their progress and consistency, adding an element of motivation and gamification to the tracking experience.

---

## 💻 Running the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/Ananya622/ChronicOne.git
```

### 2. Navigate to the project folder

```bash
cd ChronicOne
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the server

```bash
node server.js
```

The application will run at:

```text
http://localhost:3000
```

Open the address in your browser to use ChronicOne.
